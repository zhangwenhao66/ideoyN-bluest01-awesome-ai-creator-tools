# Awesome AI Creator Tools

A curated list of useful AI tools for creators, podcasters, video makers, researchers, and developers.

The list focuses on practical tools that help people record, transcribe, edit, subtitle, publish, and reuse content.

## Audio and video transcription

- [WhisperWebUI](https://whisperwebui.net/) - Transcribe audio and video in a browser and export TXT, SRT, VTT, and PDF files.
- [OpenAI Whisper](https://github.com/openai/whisper) - Open-source automatic speech recognition model supporting multiple languages.
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) - A faster Whisper implementation using CTranslate2.
- [whisper.cpp](https://github.com/ggml-org/whisper.cpp) - Port of Whisper to C/C++ with support for local and edge devices.
- [AssemblyAI](https://www.assemblyai.com/) - Speech-to-text API with transcription and audio intelligence features.
- [Otter.ai](https://otter.ai/) - Transcription and notes for meetings, interviews, and conversations.

## Local Whisper tools

- [WhisperX](https://github.com/m-bain/whisperX) - Whisper transcription with word-level timestamps and speaker diarization.
- [Whisper Web](https://github.com/louisfb01/whisper-web) - Browser interface for running Whisper locally.
- [Buzz](https://github.com/chidiwilliams/buzz) - Desktop application for transcribing and translating audio with Whisper.
- [MacWhisper](https://goodsnooze.gumroad.com/l/macwhisper) - Desktop Whisper transcription app for macOS.

## Subtitle and caption tools

- [Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) - Open-source subtitle creation, editing, synchronization, and conversion tool.
- [Aegisub](https://github.com/Aegisub/Aegisub) - Advanced subtitle editing and styling application.
- [Jubler](https://jubler.org/) - Subtitle editor for creating and converting subtitle files.
- [FFmpeg](https://ffmpeg.org/) - Powerful media conversion framework useful for audio and video workflows.

## Podcast and video creation

- [Descript](https://www.descript.com/) - Edit audio and video by editing a transcript.
- [Riverside](https://riverside.fm/) - Remote recording platform for podcasts, interviews, and video.
- [OBS Studio](https://obsproject.com/) - Free and open-source software for recording and live streaming.
- [CapCut](https://www.capcut.com/) - Video editor with captions, templates, and AI-assisted editing.
- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) - Professional video editing, color, audio, and visual effects software.

## Text and writing tools

- [ChatGPT](https://chatgpt.com/) - General-purpose AI assistant for drafting, summarizing, and transforming transcripts.
- [Claude](https://claude.ai/) - AI assistant for analysis, writing, and long-document workflows.
- [Grammarly](https://www.grammarly.com/) - Writing assistance for clarity, grammar, and tone.
- [LanguageTool](https://languagetool.org/) - Multilingual grammar and style checker.

## Developer resources

- [whisperwebui-transcript-utils](https://www.npmjs.com/package/whisperwebui-transcript-utils) - Dependency-free utilities for cleaning transcripts and generating SRT or VTT subtitles.
- [Hugging Face Audio Models](https://huggingface.co/models?pipeline_tag=automatic-speech-recognition) - Collection of automatic speech recognition models.
- [Awesome README](https://github.com/matiassingers/awesome-readme) - Examples and guidance for creating useful README files.

## How to suggest a tool

Please open an issue or pull request with:

- The tool name and official URL
- A short, factual description
- The relevant category
- Why the tool is useful for creators

Please avoid duplicate entries, affiliate links, and unsupported promotional claims.
